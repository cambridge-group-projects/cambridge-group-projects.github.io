
Client: Martina Sciola <msciola@mathworks.com>

Modern medical imaging devices like portable ultrasound systems must process large sensor datasets in real time. They require fast pipelines for signal acquisition, image reconstruction, enhancement, and AI-based interpretation. Your task is to build a real-time image processing and interpretation pipeline for a medical imaging use case. You will capture analogue signals using Analog Devices hardware or simulated datasets. Next, you will design MATLAB algorithms to reconstruct images, enhance them, and perform simple AI inference tasks. Finally, you will compile these algorithms to CUDA using GPU Coder and deploy them onto edge hardware using Holoscan for real-time streaming applications.
