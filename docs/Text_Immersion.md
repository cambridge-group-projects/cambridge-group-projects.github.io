
Client: Sandy Solomon, <sandy@docgreg.com>

Build a technical platform and interactive tool enabling an artist to synchronize points of colored light moving in 3D space with audio of the spoken word—in this case, poetry—for an immersive dark-room installation. Design a system that can dynamically trigger light arrays based on the acoustic and linguistic properties of English. Utilize an industry-standard lighting protocol (e.g., DMX512 or Art-Net) to drive the physical hardware governing these light arrays. Create a VR screen preview so the artist can visualize and synchronize the display.
